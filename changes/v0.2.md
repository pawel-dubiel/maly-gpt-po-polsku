# Wersja 0.2 — Czyste RoPE, natywne SDPA i szybka walidacja ze skokiem (Stride)

**Wersja:** `0.2`  
**Data:** 2026-10-04

---

## 1. Zakres zmian w wersji 0.2 (względem wersji 0.1)

Po rezygnacji ze sztywnych ograniczeń starych testów jednostkowych wprowadzono kolejne usprawnienia architektoniczne i wydajnościowe:

1. **Przejście na czyste RoPE — całkowite usunięcie `position_embedding` ([`model.py`](../model.py), [`test_model.py`](../test_model.py)):**
   - Usunięto wyuczalną macierz `position_embedding` z `matrix_shapes` i wejścia modelu (`x = self.dropout(w["token_embedding"][ids])`).
   - Model koduje pozycje wyłącznie względnie poprzez **RoPE** w każdej głowie i warstwie attention (architektura LLaMA / Mistral).
   - Liczba parametrów spadła z `467 584` do **`459 392`** (`-8 192` parametrów), a `validation_loss` poprawił się dodatkowo z `3,427173` (w v0.1) do **`3,418702`** (w v0.2).
2. **Natywne `F.scaled_dot_product_attention` w `GPT.forward()` ([`model.py`](../model.py)):**
   - Metoda `forward()` używana w treningu i ewaluacji korzysta bezpośrednio ze zoptymalizowanego kernela C++ `F.scaled_dot_product_attention(q, k, v, is_causal=True, dropout_p=dropout_p)`.
   - Metoda `forward_with_attention()` została zachowana dla `predict_gpt.py`, aby nadal można było wypisywać jawne macierze uwagi dla każdej głowy.
3. **Walidacja i ocena końcowa ze skokiem `stride = context_size // 2` ([`train_bpe.py`](../train_bpe.py)):**
   - Zamiast oceniać podczas każdej walidacji wszystkie `21 759` nakładających się co 1 token okien (co liczyło każdy token 64 razy), zastosowano skok `stride = max(1, model.context_size // 2)`.
   - Pierwszy krok (z walidacją i zapisem) przyspieszył z `9,32 s` (v0.1) do **`0,94 s`** (v0.2), a końcowa ocena całego korpusu trwa **1,5 s** zamiast **55–107 s**.
4. **Wektorowa walidacja tensorów i kompaktowy zapis JSON ([`model.py`](../model.py)):**
   - Usunięto potrójnie zagnieżdżone pętle walidujące listy w czystym Pythonie przy zapisie modelu oraz zastosowano kompaktowy format JSON (`separators=(",", ":")`), zmniejszając rozmiar `tiny_gpt.json` z `14,06 MB` do **`9,16 MB`**.
